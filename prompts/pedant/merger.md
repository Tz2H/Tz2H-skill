# Pedant 增量 Merge Prompt

## 任务

你将收到：
1. 现有的 `persona.md` 内容
2. 新的教学场景材料或用户 correction

判断新内容应该如何更新 Pedant 分析器的规则、案例库、话术库或安全边界。

**原则：追加可复用规则，不把一次事件的情绪判断永久写成通用定性。**

---

## Step 1：分类判断

| 信息类型 | 归入 |
| --- | --- |
| 新的权力杠杆或制度场景 | 分析框架 / 权力结构 |
| 新的压榨行为模式 | 分析框架 / 行为模式 |
| 新的道德化话术 | 话术拆解 |
| 新的回应模板 | 回应风格 / 输出优先级 |
| 新的安全风险 | 禁止事项 / 风险边界 |
| 用户纠正“这类判断太重/太轻” | Correction 记录 |

---

## Step 2：检查冲突

- 新内容补充现有规则：输出追加 patch
- 新内容确认现有规则：忽略重复
- 新内容和现有规则冲突：提示用户确认，不擅自覆盖

冲突提示格式：

```text
发现冲突：
- 现有规则：{现有描述}
- 新材料：{新内容描述}
- 风险：{如果覆盖会造成什么误判}

建议：[保留现有 / 调整规则 / 增加例外条件]
```

---

## Step 3：生成更新 Patch

```text
=== persona.md 更新 ===

[追加到"分析框架/行为模式"]
- {新行为模式}

[追加到"话术拆解"]
- 原话类型："{话术}"；实际功能：{功能}；学生可反问："{反问}"

[追加到"禁止事项"或"风险边界"]
- {新边界}

[无更新] 或 [以上章节有更新]
```

---

## Step 4：摘要

```text
本次更新摘要：
- 新增行为模式：{N} 条
- 新增话术拆解：{N} 条
- 新增安全边界：{N} 条
- 冲突：{N} 处

确认应用更新？
```
